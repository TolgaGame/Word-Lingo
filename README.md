# Word-Lingo

A simple and interactive web application for learning **2000+ English words** by matching their Turkish and English meanings.

## About

This project is a lightweight language-learning application built with classic **HTML, CSS, and JavaScript**.

The app contains a vocabulary database with **2000+ English words** and their Turkish translations. Users can practice vocabulary by matching Turkish words with their corresponding English words.

The goal is to make vocabulary practice simple, fast, and engaging without requiring any framework or installation.

## Features

* 🇹🇷 Turkish → English word matching
* 🇬🇧 English → Turkish word matching
* 📚 2000+ vocabulary words
* 🔀 Randomized questions and answers
* 🧠 Vocabulary practice and repetition
* 📊 Score tracking
* ⚡ Fast and lightweight
* 📱 Responsive design
* 🌐 Works directly in the browser
* 🚫 No backend required
* 🚫 No framework required

## How It Works

1. The application selects a word from the vocabulary database.
2. The user sees the Turkish or English version.
3. Several possible translations are displayed.
4. The user selects the matching word.
5. The application checks the answer.
6. The score is updated.
7. A new word is displayed.
